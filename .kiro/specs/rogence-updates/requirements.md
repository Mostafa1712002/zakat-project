# متطلبات تحديثات نظام Rogence

## نظرة عامة
تحديثات وتحسينات شاملة للنظام بناءً على ملاحظات العميل

---

## المرحلة 1: تنظيف الحقول والواجهات (سهل)

### 1.1 إزالة الحقول غير اللازمة
- [ ] إزالة حقول: الباركود، الإيميل، الرقم القومي من الصفحات المختلفة
- [ ] مراجعة جميع صفحات الإدخال وإزالة الحقول الزائدة

### 1.2 صفحة إنشاء فاتورة مشتريات
- [ ] إزالة حقل "رقم فاتورة المورد"
- [ ] إزالة قسم "💰 الخصم والشحن" بالكامل

### 1.3 إصلاح الريسبونسيف
- [ ] إصلاح ريسبونسيف صفحة إضافة مندوب جديد (الشاشة الكبيرة)
- [ ] إصلاح ريسبونسيف الـ Sidebar
- [ ] إصلاح ريسبونسيف الجداول

---

## المرحلة 2: تصنيف المندوبين (سهل)

### 2.1 إضافة تصنيف المندوب
- [ ] إضافة حقل `type` في جدول `sales_reps` (enum: 'fridge', 'special')
- [ ] تحديث صفحة إنشاء/تعديل المندوب
- [ ] عرض التصنيف في قائمة المندوبين

---

## المرحلة 3: نظام صلاحيات الموظفين (متوسط)

### 3.1 إضافة حساب موظف بصلاحيات محدودة
- [ ] إنشاء دور "موظف" في نظام الصلاحيات
- [ ] تحديد الصلاحيات: فواتير البيع/الشراء، إضافة الأصناف، المخازن، التحويلات
- [ ] ربط المستخدم بالموظف (مثل ربط المندوب)
- [ ] تحديث صفحة إضافة مستخدم جديد

---

## المرحلة 4: نظام المخازن المتقدم (متوسط)

### 4.1 صفحة تفاصيل المخزن
- [ ] إنشاء صفحة تعرض الأصناف في كل مخزن
- [ ] عرض عدد الوحدات المتاحة لكل صنف
- [ ] فلترة وبحث بالأصناف

### 4.2 التحقق من الكمية عند البيع
- [ ] منع إنشاء فاتورة بيع إذا الكمية غير متاحة
- [ ] عرض الكمية المتاحة أثناء إضافة الصنف
- [ ] رسالة خطأ واضحة عند تجاوز الكمية

### 4.3 تحديث المخزون التلقائي
- [ ] خصم الكمية المباعة من المخزن تلقائياً
- [ ] تحديث المخزون عند ترحيل الأصناف

---

## المرحلة 5: نظام الدفع الآجل (متوسط)

### 5.1 دفع العميل للمستحقات
- [ ] صفحة/زر لتسجيل دفعة من العميل
- [ ] ربط الدفعة بالفاتورة/الفواتير
- [ ] تحديث رصيد العميل
- [ ] إضافة الدفعة للخزنة

### 5.2 تاريخ الاستحقاق
- [ ] توضيح آلية تاريخ الاستحقاق
- [ ] تنبيهات الفواتير المتأخرة

### 5.3 نفس النظام لفواتير الشراء
- [ ] دفع المستحقات للمورد
- [ ] تحديث رصيد المورد
- [ ] خصم من الخزنة

---

## المرحلة 6: تحسينات حساب المندوب (صعب)

### 6.1 صفحة فاتورة مبيعات المندوب
- [ ] تغيير "الخصم" إلى "خدمة"
- [ ] إزالة: مصاريف الشحن، الملاحظات، سعر الجملة، الخصم من الأصناف
- [ ] منع كتابة سعر أقل من "أقل سعر للبيع"
- [ ] إضافة زر الطباعة
- [ ] تحسين ديزاين الفاتورة للطباعة
- [ ] إضافة رقم مشرف الخط ورقم المندوب

### 6.2 خزنة المندوب
- [ ] إنشاء جدول `sales_rep_treasury` أو حقل في `sales_reps`
- [ ] صفحة خزنة لكل مندوب
- [ ] صفحة مصروفات خاصة بالمندوب (بنزين، صيانة، أكل، شرب)
- [ ] زر سحب للأدمن (ينقل للخزنة الرئيسية)
- [ ] تصفير خزنة المندوب بعد السحب
- [ ] عدم ظهور خزنة المندوب للأدمن إلا عند السحب

### 6.3 مخزن المندوب
- [ ] صفحة مخزن خاصة بالمندوب
- [ ] عرض الأصناف وعدد الوحدات
- [ ] ربط المبيعات بمخزن المندوب
- [ ] عرض الكمية المتاحة أثناء إنشاء الفاتورة
- [ ] خصم المباع من مخزن المندوب

---

## المرحلة 7: تحسينات متنوعة

### 7.1 نسبة/خصم للعملاء (تارجت)
- [ ] إضافة نظام خصومات للعملاء
- [ ] ربطه بالتارجت

### 7.2 إصلاح تعديل أسماء الصفحات
- [ ] إصلاح مشكلة تعديل أسماء الصفحات في الـ Sidebar من الإعدادات
