## 🎯 نظرة عامة على النظام

نظام CRM متكامل يحتوي على **11 وحدة رئيسية** مع دعم كامل لعمليات CRUD.

### 🔹 الوحدات الرئيسية:

**1. لوحة التحكم** (Dashboard)
   - الوصف: عرض الإحصائيات والمبيعات الشهرية والسنوية، ملخص الفواتير والمشتريات، أحدث العمليات
   - العمليات: Read

**2. الفواتير** (Invoices)
   - الوصف: إدارة فواتير البيع مع طباعة الفواتير، البحث والفلترة، تتبع حالة الدفع
   - العمليات: Create, Read, Update, Delete, Print

**3. المشتريات** (Purchases)
   - الوصف: إدارة فواتير الشراء من الموردين، تتبع المخزون، حساب التكاليف
   - العمليات: Create, Read, Update, Delete

**4. الموظفين** (Employees)
   - الوصف: إدارة بيانات الموظفين والرواتب والمعلومات الشخصية
   - العمليات: Create, Read, Update, Delete

**5. العملاء** (Customers)
   - الوصف: إدارة قاعدة بيانات العملاء، معلومات الاتصال، سجل المعاملات
   - العمليات: Create, Read, Update, Delete

**6. المنتجات** (Products)
   - الوصف: إدارة كتالوج المنتجات، الأسعار، الكميات، الأقسام
   - العمليات: Create, Read, Update, Delete

**7. الموردين** (Suppliers)
   - الوصف: إدارة بيانات الموردين، معلومات الاتصال، سجل المشتريات
   - العمليات: Create, Read, Update, Delete

**8. المخازن** (Warehouses)
   - الوصف: إدارة المخازن المتعددة، نقل المخزون بين المخازن، تتبع المستويات
   - العمليات: Create, Read, Update, Delete, Transfer

**9. المبيعات** (Sales)
   - الوصف: تتبع عمليات البيع اليومية، الإيرادات، والأرباح
   - العمليات: Create, Read, Update, Delete

**10. المصروفات** (Expenses)
   - الوصف: إدارة المصروفات والتكاليف التشغيلية، تصنيف المصروفات
   - العمليات: Create, Read, Update, Delete

**11. التقارير** (Reports)
   - الوصف: تقارير مالية وإحصائية: المبيعات، المشتريات، الأرباح والخسائر، المصروفات
   - العمليات: Read, Generate, Export

## 🎨 مميزات تجربة المستخدم

### ✅ نقاط القوة
- واجهة عربية كاملة مع دعم RTL
- تصميم متجاوب على جميع الأجهزة
- تنظيم واضح ومنطقي للمحتوى
- عمليات CRUD سهلة ومباشرة
- بحث وفلترة متقدمة
- إحصائيات وتقارير شاملة

### 🚀 التقنيات المستخدمة
- **Backend:** Laravel 12 + PHP 8.2
- **Frontend:** Vite + Alpine.js + Tailwind CSS
- **Database:** SQLite
- **Authentication:** Laravel Breeze
- **UI Framework:** Tailwind CSS + RTL
